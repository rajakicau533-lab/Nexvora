# **App Name**: Nexvora Studio

## Core Features:

- Nexvora AI Creative Tool: An AI-powered generator that uses reasoning to decide parameters for text-to-image, image-to-video, and image-to-prompt transformations.
- Social Traffic Booster: Automated order system for Shopee and TikTok services using provider APIs for growth at scale.
- Integrated Coin Marketplace: A complete ecosystem for buying, earning, and spending platform koin for digital products and downloads.
- Educational Material Hub: Secure area for video lessons with integrated user reward 'Gifting' functionality using Firestore to track distributions.
- Verified Auth & OTP: Secure member registration featuring email OTP verification and encrypted password hashing for premium data protection.
- Referral Reward Network: Unique code tracking system with automated bonus calculation stored in Firestore when referred users purchase koin.
- Admin Control Center: Advanced RBAC panel for Super Admins and Assistants to manage transactions, monitor logs, and approve top-up requests.

## Style Guidelines:

- Primary Color: Vibrant Amber Gold (#F59E0B) to evoke professional prestige and wealth.
- Background Color: Deep Cocoa Brown (#1A1410), a highly desaturated dark scheme that creates a luxury high-end feel.
- Accent Color: Saturated Burnt Orange (#EA580C) for critical action buttons and key highlights, contrasting perfectly with the dark brown base.
- Headline and Body Pairing: 'Space Grotesk' for tech-oriented headers to match the 'Creator AI' aesthetic, paired with 'Inter' for clear, machin-readable UI text across complex dashboard data.
- Thin-line golden vector icons that emphasize a sleek, digital studio workspace aesthetic.
- Clean sidebar-driven architecture for both desktop and mobile to ensure professional management of multiple service modules.
- Fluid, high-frequency 2-second carousel transitions and 10-second green pop-up feedback loops for order processing success.
